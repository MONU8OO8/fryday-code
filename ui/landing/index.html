How it works

One task, a small team, and you at the two moments that matter: when something only you can decide comes up, and before anything is pushed, merged or deployed.

UnderstandPlan

It works out what you mean

The Understander reads the task and your documents and asks only what changes what gets built. The Planner writes a short design, acceptance criteria and a test plan.

BuildCheck

It builds, and checks its own work

The Builder edits a separate workspace, never your checkout. Your project's own tests run on exactly what was committed; a failure goes back to the Builder. The Checker reviews the change against the plan.

Your OKLive

You say yes, then it ships to staging

You see what passed and what will happen. Only after you approve does the Releaser merge into your staging branch and start the staging deploy. Production is never touched.

Safe by design

The engine, not the agents, decides what may happen. Every limit fails closed.

Sandbox

Agents' commands run in an operating-system sandbox: no network, writes only inside the task's workspace, your home folder unreadable.

Guard

Every tool call passes a default-deny guard. Files that look like secrets are refused, and agents never run git or your repository's hooks.

Approvals

Every push, merge and deploy needs your approval on a ticket bound to the exact commit, listing every push it will make. The agents are Claude Code, so the task and the code they read go to the AI model provider.

Staging only

FryDay Code merges into staging and deploys staging. It never answers a deploy prompt that mentions production, and production data is never granted to a tester.

How it fits together

Everything runs on your computer, as you, with the Claude Code you are already signed in to.

Install

Pick one. Each needs Node.js 22.12 or newer and Claude Code, except Docker, which needs Docker and a Claude login or API key. macOS and Linux; Windows through Docker or WSL.

From npm

Starts FryDay Code on http://127.0.0.1:7475.

npx fryday-code
npx fryday-code open   # a new one-time link

With Docker

From a clone of the repository.

docker compose up --build -d

From a clone

Builds the UI once, then starts it.

git clone https://github.com/OWNER/fryday-code.git
cd fryday-code
npm run setup
npm start

Just trying it?

The local demo needs no Claude account and costs nothing: stand-in agents on a sample project. npx fryday-code doctor checks your computer first.

npx fryday-code demo
