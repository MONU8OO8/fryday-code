# Simple UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give FryDay Code a simple, animated Home / History / Setup UI that a non-technical person can use, per `docs/design/specs/2026-11-22-simple-ui-design.md`.

**Architecture:**
- **Core** gets three small pure modules: `plainWords.ts` (actor names, plain sentences), `journey.ts` (the six stops, grouped from the existing flow model) and `story.ts` (the team chat, built from stored facts).
- **Core** also gets two read-only routes: `GET /api/tasks/overview` and `GET /api/tasks/:id/story`.
- **UI:** the theme switches to CSS variables, which restyles every existing screen light/dark at once. New Home, History and Setup screens are built on the two routes. Old routes redirect to the new places.

**Tech Stack:**
- Core: TypeScript run with tsx, Express 5, better-sqlite3, node:test.
- UI: React 18, react-router-dom, Tailwind 3, lucide-react, clsx.
- No new dependencies.

## Global Constraints

- No commits unless the owner asks for them. Each task ends with its tests green, not with a commit.
- No new npm packages, in core or UI.
- Core behaviour does not change. Agents, guard, sandbox, approvals and the pipeline stay as they are; only the two read-only routes are added.
- Agent names in the UI: Understander, Planner, Builder, Automatic checks, Checker, App tester, Page tester, Releaser, FryDay, You.
- Journey stops: Understand, Plan, Build, Check, Your OK, Live.
- Words that never appear outside Technical details or Setup: token, MCP, worktree, run, round (shown as "fixed once / twice"), diff, commit, branch (except in More options), CI, sandbox, guard.
- Chat `text` never contains a file path or a tool name.
- Buttons say what they do: "Approve", "Not yet", "Answer", "Start", "Let it go on".
- Light theme by default; calm dark when `prefers-color-scheme: dark`. All motion respects `prefers-reduced-motion`.
- Nothing specific to one person, company or machine goes into the repo.
- Core test command: `cd core && node --import tsx --test test/<name>.test.ts`. UI check: `cd ui && npx tsc --noEmit -p . && npm run build`.

/**
 * Plain words for the simple UI: who the agents are and what they are doing, said to
 * someone who is not a developer. No paths, no tool names.
 */

export type Actor = 'understander' | 'planner' | 'builder' | 'checks' | 'checker' | 'app_tester' | 'page_tester' | 'releaser' | 'fryday' | 'you';

export const ACTOR_NAME: Record<Actor, string> = {
  understander: 'Understander', planner: 'Planner', builder: 'Builder', checks: 'Automatic checks', checker: 'Checker',
  app_tester: 'App tester', page_tester: 'Page tester', releaser: 'Releaser', fryday: 'FryDay', you: 'You',
};

const OF_ROLE: Record<string, Actor> = {
  analyst: 'understander', planner: 'planner', coder: 'builder', tester: 'checker', reviewer: 'checker',
  api_tester: 'app_tester', ui_tester: 'page_tester', fryday: 'fryday', system: 'fryday', owner: 'you',
};

export function actorOfRole(role: string): Actor {
  return OF_ROLE[role] ?? 'fryday';
}

/** One line, at most `max` characters. */
export function clip(text: string, max = 280): string {
  const flat = text.replace(/\s+/g, ' ').trim();
  return flat.length > max ? `${flat.slice(0, max - 1).trimEnd()}…` : flat;
}

/** Paths become their last part: "src/cart/total.js" → "total.js". */
export function plainText(text: string): string {
  return text.replace(/(?:[\w.@~-]+\/)+([\w.@-]+)/g, '$1');
}

const CHECK_WORDS: Record<string, string> = { test: 'the tests', lint: 'the style check', typecheck: 'the type check' };
export function checkName(name: string): string {
  return CHECK_WORDS[name] ?? 'a check';
}

/** "src/cart/total.js" → "total". Never a path. */
function placeName(hint: string): string {
  const token = hint.trim().split(/\s+/)[0] ?? '';
  const last = token.split('/').filter(Boolean).pop() ?? '';
  return last.replace(/\.[A-Za-z0-9]+$/, '').replace(/[^A-Za-z0-9 _-]/g, '').slice(0, 40);
}

/** What an agent is doing now, from its latest tool calls. */
export function doingText(tools: string[], toolInputs: string[], text: string): string {
  const i = tools.length - 1;
  if (i < 0) return text.trim() ? 'Thinking it through' : 'Getting started';
  const tool = tools[i]!;
  const hint = toolInputs[i] ?? '';
  const place = placeName(hint);
  const code = place ? `the ${place} code` : 'the code';
  if (tool.startsWith('mcp__fryday_service__')) return 'Trying the app';
  if (tool.startsWith('mcp__fryday_browser__')) return 'Using the pages in a browser';
  if (tool.startsWith('mcp__')) return 'Looking at the test data';
  switch (tool) {
    case 'Read':
    case 'LS':
      return `Reading ${code}`;
    case 'Grep':
    case 'Glob':
      return 'Searching the code';
    case 'Edit':
    case 'Write':
    case 'MultiEdit':
    case 'NotebookEdit':
      return `Changing ${code}`;
    case 'Bash': {
      const cmd = hint.toLowerCase();
      if (/\b(test|jest|vitest|mocha|pytest)\b/.test(cmd)) return 'Running the tests';
      if (/\b(lint|eslint)\b/.test(cmd)) return 'Running the style check';
      if (/\b(tsc|typecheck)\b/.test(cmd)) return 'Running the type check';
      if (/\b(install|ci)\b/.test(cmd)) return 'Installing what the project needs';
      return 'Running a command';
    }
    case 'StructuredOutput':
      return 'Writing up the result';
    default:
      return 'Working on it';
  }
}

export function joinWords(parts: string[]): string {
  if (parts.length <= 1) return parts[0] ?? '';
  return `${parts.slice(0, -1).join(', ')} and ${parts[parts.length - 1]}`;
}

export const capital = (text: string) => (text ? text[0]!.toUpperCase() + text.slice(1) : text);

export const times = (n: number) => (n === 1 ? 'once' : n === 2 ? 'twice' : `${n} times`);
```

/**
 * The journey line of the simple UI: six stops, each a group of nodes of the flow model
 * (flow.ts), so the line can never disagree with where core says the task is.
 */

import type { TaskFlow, FlowNode, FlowNodeId, FlowNodeState } from './flow.js';

export type StopId = 'understand' | 'plan' | 'build' | 'check' | 'approve' | 'live';
export type StopState = 'idle' | 'active' | 'waiting' | 'done' | 'failed' | 'skipped';

export interface Journey {
  stops: Array<{ id: StopId; state: StopState }>;
  current: StopId | null;
  /** How many times the change went back to the Builder. */
  sendbacks: number;
  finished: 'live' | 'stopped' | null;
}

export const STOP_ORDER: StopId[] = ['understand', 'plan', 'build', 'check', 'approve', 'live'];

const STOP_NODES: Record<StopId, FlowNodeId[]> = {
  understand: ['analyst'],
  plan: ['planner'],
  build: ['coder'],
  check: ['checks', 'reviewer', 'api_tester', 'ui_tester'],
  approve: ['owner'],
  live: ['release', 'deploy'],
};

function stopOfNode(node: FlowNodeId): StopId {
  return STOP_ORDER.find((id) => STOP_NODES[id].includes(node))!;
}

function stopState(states: FlowNodeState[], currentState: FlowNodeState | null): StopState {
  if (currentState === 'active' || currentState === 'waiting') return currentState;
  const real = states.filter((s) => s !== 'skipped');
  if (real.length === 0) return 'skipped';
  if (real.includes('failed')) return 'failed';
  if (real.includes('done')) return 'done';
  return 'idle';
}

export function journeyOf(flow: TaskFlow, taskState: string): Journey {
  const byId = new Map<FlowNodeId, FlowNode>(flow.nodes.map((n) => [n.id, n]));
  const currentNode = flow.current?.node ?? null;
  const stops = STOP_ORDER.map((id) => {
    const nodes = STOP_NODES[id].map((n) => byId.get(n)).filter((n): n is FlowNode => n !== undefined);
    const here = currentNode !== null && STOP_NODES[id].includes(currentNode) ? byId.get(currentNode)?.state ?? null : null;
    return { id, state: stopState(nodes.map((n) => n.state), here) };
  });
  return {
    stops,
    current: currentNode ? stopOfNode(currentNode) : null,
    sendbacks: flow.edges.filter((e) => e.kind === 'sendback').length,
    finished: taskState === 'deployed' ? 'live' : taskState === 'failed' ? 'stopped' : null,
  };
}

export type TaskGroup = 'needs_you' | 'working' | 'done';

export function groupOf(state: string): TaskGroup {
  if (state === 'waiting_owner' || state === 'awaiting_approval' || state === 'needs_owner') return 'needs_you';
  if (state === 'deployed' || state === 'failed') return 'done';
  return 'working';
}

const WORKING_LINE: Record<StopId, string> = {
  understand: 'The Understander is reading the task',
  plan: 'The Planner is working out the change',
  build: 'The Builder is making the change',
  check: 'The change is being checked',
  approve: 'Waiting for you',
  live: 'Being released to staging',
};

export function overviewLine(state: string, journey: Journey): string {
  switch (state) {
    case 'queued': return 'Waiting to start';
    case 'waiting_owner': return 'Has a question for you';
    case 'awaiting_approval': return 'Ready: needs your OK';
    case 'needs_owner': return 'Stopped: needs you';
    case 'deployed': return 'Done: on staging';
    case 'failed': return 'Stopped';
    default: return journey.current ? WORKING_LINE[journey.current] : 'Working on it';
  }
}
```

/**
 * The team chat of the simple UI, built only from facts core stores: hand-offs, plans,
 * check results, verdicts, tester reports, questions, approvals and releases. No model
 * writes these lines; where a line quotes an agent (a brief, a plan, a verdict), it is that
 * agent's stored output, with paths taken out.
 */

import { hasBlockingFlag } from './diffFlags.js';
import type { QuestionOption } from './questions.js';
import type { Round } from './rounds.js';
import { ACTOR_NAME, actorOfRole, capital, checkName, clip, doingText, joinWords, plainText, times, type Actor } from './plainWords.js';

export type StoryKind = 'said' | 'handoff' | 'sendback' | 'question' | 'approval' | 'note' | 'outcome';

export type DetailRef =
  | { kind: 'brief' }
  | { kind: 'plan' }
  | { kind: 'round'; round: number; part: 'checks' | 'verdict' | 'changes' | 'verify' }
  | { kind: 'deploy' };

export type StoryAction =
  | { kind: 'answer'; questionId: string; options: QuestionOption[] }
  | { kind: 'approve'; approvalId: string; plain: string; effects: string[] };

export interface StoryItem {
  /** Stable between calls, so the UI animates only new items. */
  id: string;
  at: number;
  from: Actor;
  to: Actor | null;
  kind: StoryKind;
  text: string;
  round: number | null;
  details: { label: string; ref: DetailRef } | null;
  action: StoryAction | null;
}

export interface StoryNow {
  actor: Actor;
  text: string;
  since: number;
}

export interface StoryInput {
  task: { id: string; title: string; description: string; state: string; createdAt: number; note: string | null };
  projectName: string | null;
  brief: { summary: string; at: number } | null;
  plan: { summary: string; criteria: number; at: number } | null;
  questions: Array<{ id: string; question: string; options: QuestionOption[]; askedBy: string; askedAt: number; answer: string | null; answeredAt: number | null }>;
  rounds: Array<Round & { createdAt: number }>;
  /** The owner's notes on the task. */
  notes: Array<{ id: number; body: string; at: number }>;
  /** Things agents posted on the task thread (the Analyst's "this is for …"). */
  agentEvents: Array<{ id: number; author: string; body: string; at: number }>;
  approvals: Array<{ id: string; action: string; state: string; payload: Record<string, unknown>; requestedAt: number; resolvedAt: number | null }>;
  release: { id: string; state: string; at: number } | null;
  deploy: { id: string; state: string; at: number } | null;
}

const said = (text: string, max = 280) => clip(plainText(text), max);
const str = (v: unknown) => (typeof v === 'string' ? v : '');
const strings = (v: unknown) => (Array.isArray(v) ? v.filter((x): x is string => typeof x === 'string') : []);

/** What approving does, in one or two plain sentences. The technical list stays beside it. */
export function plainApproval(action: string, payload: Record<string, unknown>, projectName: string | null): string {
  const project = str(payload['repoName']) || projectName || 'the project';
  switch (action) {
    case 'release_stg':
      return `When you approve, the change is added to ${project} and put on staging. Nothing goes live for customers.`;
    case 'push_branch':
      return payload['owned'] === true
        ? `When you approve, the work is added to the branch you started (${str(payload['targetBranch'])}).`
        : `When you approve, the work is shared on a new branch so the owner of ${str(payload['targetBranch'])} can review it.`;
    case 'deploy_stg':
      return `When you approve, the new version of ${project} is started on the staging server. Nothing goes live for customers.`;
    case 'deploy_input':
      return 'The staging deploy is asking to go on. When you approve, FryDay answers yes to that one question.';
    case 'continue_budget': {
      const spentUsd = payload['spentUsd'];
      const spent = typeof spentUsd === 'number' ? ` ($${spentUsd.toFixed(2)})` : '';
      if (payload['why'] === 'task') return `This task has used its budget${spent}. Let it spend more?`;
      const stage = payload['stage'] as { role?: unknown } | undefined;
      return `The ${ACTOR_NAME[actorOfRole(str(stage?.role))]} reached its spending limit for one go. Let it go on?`;
    }
    default:
      return said(str(payload['summary']) || 'FryDay needs your OK to go on.');
  }
}

export function storyNow(live: { role: string; tools: string[]; toolInputs: string[]; text: string; since: number } | null): StoryNow | null {
  if (!live) return null;
  return { actor: actorOfRole(live.role), text: doingText(live.tools, live.toolInputs, live.text), since: live.since };
}

type NewItem = Omit<StoryItem, 'to' | 'round' | 'details' | 'action'> & Partial<Pick<StoryItem, 'to' | 'round' | 'details' | 'action'>>;

export function buildStory(input: StoryInput): StoryItem[] {
  const items: StoryItem[] = [];
  const add = (item: NewItem) => { items.push({ to: null, round: null, details: null, action: null, ...item }); };
  const t = input.task;

  add({ id: `task:${t.id}`, at: t.createdAt, from: 'you', kind: 'note', text: clip(t.description || t.title, 400) });

  if (input.brief) {
    add({ id: `brief:${t.id}`, at: input.brief.at, from: 'understander', kind: 'said', text: said(input.brief.summary), details: { label: 'What I understood', ref: { kind: 'brief' } } });
  }
  for (const e of input.agentEvents) {
    if (input.brief && e.body.trim() === input.brief.summary.trim()) continue;
    add({ id: `event:${e.id}`, at: e.at, from: actorOfRole(e.author), kind: 'said', text: said(e.body) });
  }
  for (const q of input.questions) {
    const open = q.answer === null;
    add({
      id: `question:${q.id}`, at: q.askedAt, from: actorOfRole(q.askedBy), to: 'you', kind: 'question', text: said(q.question, 400),
      action: open && t.state === 'waiting_owner' ? { kind: 'answer', questionId: q.id, options: q.options } : null,
    });
    if (!open) {
      const shown = q.options.find((o) => o.value === q.answer)?.label ?? q.answer ?? '';
      add({ id: `answer:${q.id}`, at: q.answeredAt ?? q.askedAt, from: 'you', kind: 'note', text: clip(shown, 400) });
    }
  }
  // After the questions: when a note and a question share a millisecond, the question came first.
  for (const n of input.notes) add({ id: `note:${n.id}`, at: n.at, from: 'you', kind: 'note', text: clip(n.body, 400) });

  if (input.plan) {
    const n = input.plan.criteria;
    add({
      id: `plan:${t.id}`, at: input.plan.at, from: 'planner', to: 'builder', kind: 'handoff',
      text: `Here's the plan: ${said(input.plan.summary, 240)} ${n} ${n === 1 ? 'thing' : 'things'} must be true when it's done.`,
      details: { label: 'See the plan', ref: { kind: 'plan' } },
    });
  }

  for (const r of input.rounds) {
    const at = r.createdAt;
    add({
      id: `round:${r.round}`, at, from: 'builder', to: 'checks', kind: 'handoff', round: r.round,
      text: r.round === 1 ? 'Done. Please check it.' : 'Fixed. Please check again.',
      details: { label: 'What changed', ref: { kind: 'round', round: r.round, part: 'changes' } },
    });
    const failing = r.checks.filter((c) => c.status === 'failed' || c.status === 'timeout' || c.status === 'error');
    const blocked = hasBlockingFlag(r.flags);
    if (failing.length > 0 || blocked) {
      const parts = failing.map((c) => `${checkName(c.name)} ${c.status === 'timeout' ? 'took too long' : c.status === 'error' ? 'could not run' : 'did not pass'}`);
      if (blocked) parts.push('the change does something FryDay does not allow');
      add({
        id: `gate:${r.round}`, at: at + 1, from: 'checks', to: 'builder', kind: 'sendback', round: r.round,
        text: `${capital(joinWords(parts))}. Back to you.`, details: { label: 'What failed', ref: { kind: 'round', round: r.round, part: 'checks' } },
      });
      continue;
    }
    if (r.verdict) {
      const unmet = r.verdict.criteria.filter((c) => !c.met);
      const details = { label: 'How it was checked', ref: { kind: 'round' as const, round: r.round, part: 'verdict' as const } };
      if (r.verdict.verdict === 'pass' && unmet.length === 0) {
        add({ id: `verdict:${r.round}`, at: at + 2, from: 'checker', kind: 'said', round: r.round, text: `It meets all ${r.verdict.criteria.length} points of the plan.`, details });
      } else {
        const text = unmet.length > 0
          ? `${unmet.length} of ${r.verdict.criteria.length} points are not met yet, for example: ${said(unmet[0]!.criterion, 160)} Back to you.`
          : `${said(r.verdict.summary, 200)} Back to you.`;
        add({ id: `verdict:${r.round}`, at: at + 2, from: 'checker', to: 'builder', kind: 'sendback', round: r.round, text, details });
        continue;
      }
    }
    const v = r.verify;
    if (!v) continue;
    const details = { label: 'What was tried', ref: { kind: 'round' as const, round: r.round, part: 'verify' as const } };
    if (v.startFailure) {
      const failed = v.status === 'failed';
      add({
        id: `verify:${r.round}:start`, at: at + 3, from: 'app_tester', to: failed ? 'builder' : null, kind: failed ? 'sendback' : 'said', round: r.round, details,
        text: failed ? 'The app does not start with the change. Back to you.' : 'The app could not be started to try it, so this goes to you.',
      });
      continue;
    }
    for (const tester of v.testers) {
      const who: Actor = tester.kind === 'api' ? 'app_tester' : 'page_tester';
      const tried = tester.kind === 'api' ? `Tried the app ${times(tester.calls)}` : `Used the pages ${times(tester.calls)}`;
      if (tester.passed) {
        add({ id: `verify:${r.round}:${tester.kind}`, at: at + 3, from: who, kind: 'said', round: r.round, text: `${tried}: it works as planned.`, details });
      } else {
        add({
          id: `verify:${r.round}:${tester.kind}`, at: at + 3, from: who, to: 'builder', kind: 'sendback', round: r.round, details,
          text: `${tried}. ${said(tester.report?.summary ?? 'It did not work as planned.', 200)} Back to you.`,
        });
      }
    }
  }

  let pending = false;
  for (const a of input.approvals) {
    if (a.state === 'expired') continue; // replaced by a newer one before anyone decided
    const open = a.state === 'pending';
    pending ||= open;
    const plain = plainApproval(a.action, a.payload, input.projectName);
    add({
      id: `approval:${a.id}`, at: a.requestedAt, from: a.action === 'continue_budget' ? 'fryday' : 'releaser', to: 'you', kind: 'approval', text: plain,
      action: open ? { kind: 'approve', approvalId: a.id, plain, effects: [...strings(a.payload['pushes']), ...strings(a.payload['effects'])] } : null,
    });
    if (a.resolvedAt !== null && a.state !== 'pending') {
      add({ id: `decision:${a.id}`, at: a.resolvedAt, from: 'you', kind: 'note', text: a.state === 'rejected' ? 'Not yet.' : 'Approved.' });
    }
  }

  if (input.release) {
    const r = input.release;
    const text = r.state === 'pushed' ? 'The change is on staging.'
      : r.state === 'stopped' ? 'Releasing stopped before anything changed on staging.'
      : r.state === 'reverted' ? 'The change was taken back off staging.'
      : null;
    if (text) add({ id: `release:${r.id}`, at: r.at + 1, from: 'releaser', kind: 'outcome', text });
  }
  if (input.deploy) {
    const d = input.deploy;
    const text = d.state === 'succeeded' ? 'The staging server is running the new version.'
      : d.state === 'failed' || d.state === 'stopped' ? 'The staging deploy did not finish.'
      : null;
    if (text) add({ id: `deploy:${d.id}`, at: d.at + 1, from: 'releaser', kind: 'outcome', text, details: { label: 'Deploy details', ref: { kind: 'deploy' } } });
  }

  const last = items.reduce((m, i) => Math.max(m, i.at), 0);
  if (t.state === 'needs_owner' && !pending) {
    add({ id: `stopped:${t.id}`, at: last + 1, from: 'fryday', to: 'you', kind: 'said', text: t.note ? `I stopped and need you: ${said(t.note, 300)}` : 'I stopped and need you.' });
  }
  if (t.state === 'failed') {
    add({ id: `failed:${t.id}`, at: last + 1, from: 'fryday', kind: 'said', text: t.note ? `The task stopped: ${said(t.note, 300)}` : 'The task stopped.' });
  }

  return items.sort((a, b) => a.at - b.at);
}

import { useCallback, useEffect, useRef } from 'react';

/** Calls `fn` at most once per `ms`, at the end of the window, however often it is asked. */
export function useThrottle(fn: () => void, ms: number): () => void {
  const fnRef = useRef(fn);
  fnRef.current = fn;
  const timer = useRef<number | null>(null);
  useEffect(() => () => { if (timer.current !== null) window.clearTimeout(timer.current); }, []);
  return useCallback(() => {
    if (timer.current !== null) return;
    timer.current = window.setTimeout(() => { timer.current = null; fnRef.current(); }, ms);
  }, [ms]);
}

 * to the next, the current stop pulses, and a dashed loop counts the times work went back.
 */

import { useEffect, useRef, useState } from 'react';
import clsx from 'clsx';
import type { Journey, StopState } from '../storyTypes';
import { STOPS, fixedTimes } from '../plain';

const DOT: Record<StopState, string> = {
  done: 'bg-hud-green/15',
  active: 'bg-hud-cyan/15 ring-2 ring-hud-cyan jr-pulse',
  waiting: 'bg-hud-amber/15 ring-2 ring-hud-amber jr-pulse',
  failed: 'bg-hud-amber/10 ring-1 ring-hud-amber/60',
  skipped: 'bg-hud-border/40 opacity-40',
  idle: 'bg-hud-border/60 opacity-60',
};
const SEG: Record<StopState, string> = {
  done: 'bg-hud-green', active: 'bg-hud-cyan jr-blink', waiting: 'bg-hud-amber jr-blink',
  failed: 'bg-hud-amber/60', skipped: 'bg-hud-border/50', idle: 'bg-hud-border',

/** Index of the stop the card sits at: the current one, else the last one done. */
function position(j: Journey): number {
  const cur = j.current ? STOPS.findIndex((s) => s.id === j.current) : -1;
  if (cur >= 0) return cur;
  let last = 0;
  j.stops.forEach((s, i) => { if (s.state === 'done') last = i; });
  return last;
}

function label(j: Journey): string {
  const at = STOPS[position(j)]!.name;
  return j.finished === 'live' ? 'Done: live on staging' : `${at}${j.sendbacks ? `, ${fixedTimes(j.sendbacks)}` : ''}`;
}

// Stops are 4rem wide inside 1.25rem padding: their centres run from 3.25rem to 100% - 3.25rem.
const along = (f: number) => `calc(3.25rem + (100% - 6.5rem) * ${f})`;

export default function JourneyLine({ journey, compact = false }: { journey: Journey; compact?: boolean }) {
  const f = position(journey) / (STOPS.length - 1);
  const [burst, setBurst] = useState(false);
  const wasLive = useRef(journey.finished === 'live');
  useEffect(() => {
    const live = journey.finished === 'live';
    if (live && !wasLive.current) {
      setBurst(true);
      const t = window.setTimeout(() => setBurst(false), 1200);
      wasLive.current = true;
      return () => window.clearTimeout(t);
    }
    wasLive.current = live;
  }, [journey.finished]);

  if (compact) {
    return (
      <div className="flex gap-1 mt-1.5" aria-label={label(journey)}>
        {journey.stops.map((s) => <i key={s.id} className={clsx('h-1 flex-1 rounded-full', SEG[s.state])} />)}
      </div>
    );
  }
  return (
    <div className="relative px-5 pt-2 pb-10" role="img" aria-label={label(journey)}>
      <div className="absolute top-[28px] h-1 rounded-full bg-hud-border" style={{ left: along(0), right: '3.25rem' }} />
      <div className="absolute top-[28px] h-1 rounded-full bg-gradient-to-r from-hud-green to-hud-cyan transition-[width] duration-700"

  const box = useRef<HTMLDivElement>(null);

import { Link } from 'react-router-dom';
import { useCoreApi } from '../hooks/useSse';
import type { OverviewItem } from '../storyTypes';
import { ACTORS, ago, money } from '../plain';

interface RoleUsage { role: string; runs: number; costUsd: number }
const ACTOR_OF_ROLE: Record<string, keyof typeof ACTORS> = {
  analyst: 'understander', planner: 'planner', coder: 'builder', tester: 'checker', api_tester: 'app_tester', ui_tester: 'page_tester', fryday: 'fryday', system: 'fryday',
};

export default function HistoryView() {
  const api = useCoreApi();
  const [tasks, setTasks] = useState<OverviewItem[]>([]);
  const [roles, setRoles] = useState<RoleUsage[]>([]);
  useEffect(() => {
    api.get('/tasks/overview').then((d) => setTasks((d.tasks as OverviewItem[]).filter((t) => t.group === 'done'))).catch(() => {});
    api.get('/usage/by-role?days=7').then((d) => setRoles(d.roles ?? [])).catch(() => {});
  }, []);
  const week = roles.reduce((n, r) => n + r.costUsd, 0);
  return (
    <div className="max-w-4xl mx-auto p-6 space-y-6">
      <section>
        <h1 className="text-xl font-bold mb-3">Finished tasks</h1>
        {tasks.length === 0 ? <p className="text-sm text-hud-dim">Nothing finished yet.</p> : (
          <div className="rounded-2xl bg-hud-surface border border-hud-border divide-y divide-hud-border">
            {tasks.map((t) => (
              <Link key={t.id} to={`/home/${t.id}`} className="flex items-center gap-3 px-4 py-3 hover:bg-hud-bg">
                <span className="text-lg">{t.state === 'deployed' ? '🚀' : '⏹️'}</span>
                <span className="flex-1 min-w-0">
                  <span className="block text-sm font-semibold truncate">{t.title}</span>
                  <span className="block text-xs text-hud-dim">{t.line}{t.projectName ? ` · ${t.projectName}` : ''}{t.journey.sendbacks ? ` · fixed ${t.journey.sendbacks}×` : ''}</span>
                </span>
                <span className="text-xs text-hud-dim">{ago(t.updatedAt)}</span>
              </Link>
            ))}
          </div>
        )}
      </section>
      <section>
        <h2 className="text-lg font-bold mb-1">This week</h2>
        <p className="text-sm text-hud-dim mb-3">{money(week)} spent by all agents together.</p>
        <div className="rounded-2xl bg-hud-surface border border-hud-border p-4 space-y-2">
          {roles.filter((r) => r.runs > 0).map((r) => {
            const a = ACTORS[ACTOR_OF_ROLE[r.role] ?? 'fryday'];
            return (
              <div key={r.role} className="flex items-center gap-3 text-sm">
                <span className="w-36">{a.icon} {a.name}</span>
                <span className="flex-1 h-2 rounded-full bg-hud-border overflow-hidden"><span className="block h-full rounded-full" style={{ width: `${week ? (r.costUsd / week) * 100 : 0}%`, background: a.color }} /></span>
                <span className="w-16 text-right">{money(r.costUsd)}</span>
              </div>
            );
          })}
        </div>
      </section>
    </div>
  );
}

/** Setup, for the developer: one checklist; each step opens the detailed screen for it. */

import { useEffect, useState, type ReactNode } from 'react';
import { Link } from 'react-router-dom';
import { useCoreApi } from '../hooks/useSse';

type Mark = 'done' | 'todo' | 'optional';
interface Step { title: string; why: string; to: string; mark: Mark }

export function BackToSetup({ children }: { children: ReactNode }) {
  return (
    <div>
      <div className="px-4 pt-3"><Link to="/setup" className="text-sm text-hud-cyan">← Setup</Link></div>
      {children}
    </div>
  );
}

export default function SetupView() {
  const api = useCoreApi();
  const [steps, setSteps] = useState<Step[] | null>(null);
  useEffect(() => {
    const safe = <T,>(p: Promise<T>) => p.catch(() => null);
    void Promise.all([safe(api.get('/connections')), safe(api.get('/projects')), safe(api.get('/notifications')), safe(api.get('/deploy/jenkins'))]).then(([conn, projects, notes, jenkins]) => {
      const ok = (id: string) => (conn?.checks ?? []).some((c: { id: string; state: string }) => c.id === id && c.state === 'ok');
      setSteps([
        { title: 'Claude Code', why: 'The agents run on it, signed in on this Mac.', to: '/setup/connections', mark: ok('claude') && ok('sandbox') ? 'done' : 'todo' },
        { title: 'Your projects', why: 'The code FryDay may work on.', to: '/setup/projects', mark: (projects?.repos ?? []).some((r: { verified: boolean }) => r.verified) ? 'done' : 'todo' },
        { title: 'Chat space', why: 'So FryDay can message you, and you can give tasks from Chat.', to: '/setup/connections', mark: notes?.chat?.configured ? 'done' : 'todo' },
        { title: 'Staging deploys', why: 'Jenkins, if your team deploys staging with it.', to: '/setup/connections', mark: jenkins?.jenkins?.configured ? 'done' : 'optional' },
        { title: 'Agents', why: 'Models, spending limits and engines. The defaults work.', to: '/setup/agents', mark: 'done' },
        { title: 'Data for testing', why: 'Read-only test databases the testers may look at.', to: '/setup/connections', mark: (conn?.dataConnections ?? []).some((c: { enabled: boolean }) => c.enabled) ? 'done' : 'optional' },
      ]);
    });
  }, []);
  const icon: Record<Mark, string> = { done: '✅', todo: '⬜', optional: '◻️' };
  return (
    <div className="max-w-4xl mx-auto p-6">
      <h1 className="text-xl font-bold">Setup</h1>
      <p className="text-sm text-hud-dim mb-4">For your developer, once. Nothing here is needed day to day.</p>
      <div className="grid sm:grid-cols-2 lg:grid-cols-3 gap-3">
        {(steps ?? []).map((s) => (
          <Link key={s.title} to={s.to} className="rounded-2xl bg-hud-surface border border-hud-border p-4 hover:ring-2 hover:ring-hud-cyan/40">
            <div className="font-semibold">{icon[s.mark]} {s.title}</div>
            <div className="text-sm text-hud-dim mt-1">{s.why}</div>
            {s.mark === 'optional' && <div className="text-xs text-hud-dim mt-1">Optional</div>}
          </Link>
        ))}
      </div>
      <div className="flex flex-wrap gap-4 mt-6 text-sm">
        <Link to="/setup/activity" className="text-hud-cyan">Agent activity</Link>
        <Link to="/setup/console" className="text-hud-cyan">Talk to FryDay (console)</Link>
      </div>
    </div>
  );
}

import { useEffect, useState } from 'react';
import { Routes, Route, NavLink, Navigate, useParams } from 'react-router-dom';
import clsx from 'clsx';
import CommandDeck from './pages/CommandDeck';
import AgentsView from './pages/AgentsView';
import ReposView from './pages/ReposView';
import SettingsView from './pages/SettingsView';
import ConnectionsView from './pages/ConnectionsView';
import HomeView from './pages/HomeView';
import HistoryView from './pages/HistoryView';
import SetupView, { BackToSetup } from './pages/SetupView';
import { SessionGate } from './Session';
import Toaster from './components/Toaster';
import { useCoreApi } from './hooks/useSse';
import { money } from './plain';

const NAV = [
  { to: '/home', label: 'Home' },
  { to: '/history', label: 'History' },
  { to: '/setup', label: 'Setup' },
];

export default function App() {
  return (
    <SessionGate>
      <Shell />
    </SessionGate>
  );
}

function WeekSpend() {
  const api = useCoreApi();
  const [usd, setUsd] = useState<number | null>(null);
  useEffect(() => {
    const load = () => api.get('/usage/by-role?days=7').then((d) => setUsd((d.roles ?? []).reduce((n: number, r: { costUsd: number }) => n + r.costUsd, 0))).catch(() => {});
    void load();
    const t = window.setInterval(load, 60_000);
    return () => window.clearInterval(t);
  }, []);
  return usd === null ? null : <span className="ml-auto text-xs text-hud-dim">This week: {money(usd)} spent</span>;
}

/** An old task link (/tasks/:id) opens the task on Home. */
function TaskRedirect() {
  const { id } = useParams();
  return <Navigate to={`/home/${id}`} replace />;
}

function Shell() {
  return (
    <div className="flex flex-col h-screen overflow-hidden bg-hud-bg text-hud-bright">
      <header className="flex items-center gap-4 px-4 py-2.5 border-b border-hud-border bg-hud-surface">
        <span className="font-bold text-hud-cyan text-base">⚡ FryDay</span>
        <nav className="flex gap-1">
          {NAV.map(({ to, label }) => (
            <NavLink key={to} to={to}
              className={({ isActive }) => clsx('px-3.5 py-1.5 rounded-full text-sm', isActive ? 'bg-hud-cyan/15 text-hud-cyan font-semibold' : 'text-hud-dim hover:text-hud-bright')}>
              {label}
            </NavLink>
          ))}
        </nav>
        <WeekSpend />
      </header>

      <Toaster />

      <main className="flex-1 min-h-0 overflow-auto">
        <Routes>
          <Route index element={<Navigate to="/home" replace />} />
          <Route path="/home" element={<HomeView />} />
          <Route path="/home/:id" element={<HomeView />} />
          <Route path="/home/:id/details" element={<HomeView details />} />
          <Route path="/history" element={<HistoryView />} />
          <Route path="/setup" element={<SetupView />} />
          <Route path="/setup/projects" element={<BackToSetup><ReposView /></BackToSetup>} />
          <Route path="/setup/connections" element={<BackToSetup><ConnectionsView /></BackToSetup>} />
          <Route path="/setup/agents" element={<BackToSetup><SettingsView /></BackToSetup>} />
          <Route path="/setup/activity" element={<BackToSetup><AgentsView /></BackToSetup>} />
          <Route path="/setup/console" element={<BackToSetup><CommandDeck /></BackToSetup>} />
          {/* Earlier addresses, still used by links in Chat messages and old bookmarks. */}

    </div>
